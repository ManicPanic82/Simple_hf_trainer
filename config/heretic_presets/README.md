# Bundled Heretic presets

These TOML files are verbatim copies of the example configurations published in
[p-e-w/heretic](https://github.com/p-e-w/heretic) (`config.default.toml` and its
`config.*.toml` companions). They are loaded by the app's Heretic tab as starting
points; the "Compact / low VRAM" preset is generated by the app itself.

Heretic is AGPL-3.0 © 2025-2026 Philipp Emanuel Weidmann and contributors. The
files are kept here so the GUI can offer the real upstream presets without
requiring a network connection. They are data, not bundled engine code: the
engine still runs in its own environment.

When upstream publishes a new preset, drop its `config.<name>.toml` file here
and add a friendly label to `PRESET_LABELS` in `src/services/heretic_config.py`.
